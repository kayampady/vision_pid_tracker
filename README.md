# vision_pid_tracker with PID control

# Overview
This project implements a vision-based object tracking system using:
- OpenCV
- HSV color filtering
- Contour detection
- PID control for smooth steering

# Features
- Real-time webcam processing
- Blue object detection
- Error calculation from frame center
- PID-based steering output
- Modular design

## Future Improvements
- Add motor integration
- Add ROS2 node
- Add dynamic PID tuning
- Extend to line-following robot
